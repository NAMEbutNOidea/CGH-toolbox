# 设计包规范

设计包是网页唯一需要你写代码的地方：**给定一组参数，算出相机（近场）平面上的目标复场**。
编码、载波、反传补偿、传播、指标、出图全部由引擎负责。

## 目录结构

```
designs/<包名>/
├── manifest.json    声明名称、说明与可调参数（纯数据）
├── design.py        必须提供 target_field(params, ctx)
└── （可选）图片等资源，用相对路径读取
```

包目录名建议小写字母 + 下划线；以 `_` 开头的目录（如 `_template`）不会被扫描。

## manifest.json

```json
{
  "id": "my_pack",
  "name": "我的设计包",
  "description": "一句话说明生成什么光",
  "version": "0.1.0",
  "author": "",
  "targetPlane": "camera",
  "entry": "design.py",
  "notes": "可选说明",
  "params": [
    {
      "key": "waist_mm", "label": "光斑半径", "group": "设计参数", "type": "number",
      "default": 0.5, "unit": "mm", "min": 0.05, "max": 5, "step": 0.01,
      "sweepable": true, "sweep": { "min": 0.2, "max": 1.2, "step": 0.1 },
      "help": "这是什么参数、量级、扫描它会怎样"
    }
  ]
}
```

`type` 取值：`number` / `int` / `bool` / `enum`（需 `options: [{value,label}]`）/
`text` / `float_list` / `string_list`（后两者 default 用 JSON 数组）。
`advanced: true` 的参数在网页里收进「高级参数」折叠区。
`group` 只用于分组显示，设计包参数统一写 `"设计参数"`。

## design.py

```python
import numpy as np
import cgh_sdk as sdk


def target_field(params, ctx):
    g = ctx.grid(nx=720, ny=720, extent_m=2.5e-3)
    field = sdk.gaussian(g.x, g.y, float(params["waist_mm"]) * 1e-3)
    return {"field": field.astype(complex), "extent_m": (2.5e-3, 2.5e-3)}
```

### 参数

- `params`：键与 `manifest.json` 的 `params[].key` 一致，值已按 `type` 转换；
- 缺省值来自 manifest，用户在网页上改动后写入 `params/designs/<包名>.json`。

### 上下文 `ctx`

| 属性 | 含义 |
|---|---|
| `ctx.wavelength` | 实验激光波长（米） |
| `ctx.extent_m` | 建议覆盖口径 `(ex, ey)`（米），来自全局参数「设计包建议口径」 |
| `ctx.target_core_diameter` | 目标芯径映射（米），用于把「结构尺寸 / 纤芯」换算成物理尺寸 |
| `ctx.near_center` / `ctx.far_center` | 一级在相机平面的中心坐标（米）——**不要把位移写进场里** |
| `ctx.settings` | 全部全局参数的只读字典 |
| `ctx.sdk` | 等价于 `import cgh_sdk` |
| `ctx.grid(nx, ny=None, extent_m=None)` | 返回 `{x, y, x1, y1, nx, ny, extent_m}`，坐标单位为米 |

### 坐标约定

- 一律 **米**，相位弧度；
- `g.x` / `g.y` 是 meshgrid：**第 0 行对应 +y，第 0 列对应 −x**（与相机图像、MATLAB 一致）；
- 场必须**在 (0, 0) 居中**：一级位移由框架根据「0/+1 间距」统一施加。

### 返回值

`{"field": 二维复数数组, "extent_m": (ex, ey)}`，也接受 `(field, extent_m)` 或直接返回 `field`
（此时口径取 `ctx.extent_m`）。`extent_m` 允许写标量表示正方形。

引擎会把场按三次插值重采样到相机网格，然后：

1. 平移到一级位置并加载波；
2. 反传到 SLM 面（可选）；
3. 除以入射高斯振幅（含下限）；
4. 按所选编码方式写成 8 位相位；
5. 正向传播到近场（角谱）与远场（Collins 模型）；
6. 在零级/一级窗口内统计指标。

## 常用 SDK 函数

```python
sdk.grid(nx, ny=None, extent_m=25e-3)
sdk.gaussian(x, y, w)                     # exp(-r²/w²)，w = 强度 1/e² 半径
sdk.supergaussian(x, y, w, order=4)
sdk.disk(x, y, radius, soft=0.0)          # 圆孔（soft 单位米，>0 软边）
sdk.ring(x, y, radius, width)             # 高斯环
sdk.rect(x, y, half_x, half_y)
sdk.vortex(x, y, charge=1)
sdk.tilt(x, y, fx, fy)                    # 线性相位，空间频率 1/m
sdk.lens(x, y, focal, wavelength)
sdk.normalize(field)                      # 峰值归一到 1
sdk.normalize_energy(field)
sdk.lp_modes(core_radius=5e-6, NA=0.1, wavelength=632.8e-9,
             zone_size=100e-6, n_grid=600, max_l=6, max_m=6)   # {"LP01e": field, ...}
sdk.combo(modes, weights, phases=None, weight_type="amplitude")
sdk.image_field(path, extent_m=None, invert=False, pixel_m=None, blur_m=None)
```

## 从 MATLAB 脚本迁移

原脚本多半是 `.m`：目标图案 → 加光栅 → `ifft2` 反传到 SLM → 量化成 `uint8` → `imwrite`。
迁移时**只有目标图案要留下**，其余四步都在引擎里，必须删掉——否则会出现「加了两次载波、
目标落到错的位置、相位被量化两次」。

具体做法：顶栏「整理脚本提示词」→ 选 **MATLAB 脚本** → 复制全文 → 连同 `.m` 粘给 AI。
那份提示词含逐条语法对照、`meshgrid`/索引方向陷阱、单位换算，AI 直接产出两个文件。

手工迁移最容易错的三处：

1. **单位**：`.m` 里常以 mm 写数，`design.py` 里一律乘 `1e-3`；波长用 `ctx.wavelength` 别写死。
2. **方向**：`ctx.grid()` 的第 0 行是 +y（图像顶部）。照搬 `meshgrid` 不要转置，但
   `ndgrid` 得到的顺序是反的，要么用 `indexing="ij"`，要么转置。
3. **LP 模式**：原脚本里手解贝塞尔方程的部分不要翻译，直接用 `sdk.lp_modes()` + `sdk.combo()`。

## 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 一级窗口几乎没有光，零级很亮 | 场没有把能量放进 ±0.4 mm 的有效照明区，或幅度/相位定义反了 | 检查 `extent_m` 与实际结构尺寸；确认返回的是复场而不是幅度图 |
| 光斑被切成方形 | 场在网格边界被硬截断 | 用 `sdk.disk(..., soft=...)` 或把 `extent_m` 放大到 1.2–1.5 倍结构尺寸 |
| 光斑只有一半 | 场偏离中心 | 把结构放回 (0, 0)，位移交给「0/+1 间距」 |
| 形状对但很暗 | 目标口径远大于入射照明 | 增大「入射 1/e² 半径」或缩小目标尺寸（自检会给出弱照明能量占比） |
| 页面报「设计包加载失败」 | `design.py` 语法错或少了 `target_field` | 看自检面板里的报错行，或点「整理脚本提示词」重新交给 AI |
| `import` 报错 | 用了 numpy/scipy 之外的库 | 只允许 numpy、scipy、cgh_sdk；图片读取用 `sdk.image_field` |
