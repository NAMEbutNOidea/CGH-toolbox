# CGH 工具箱

本地网页工具：**加载设计包 → 调参数 → 生成相位型 CGH（8 位 BMP）→ 仿真近/远场相机图 → 自动算 1/e² 半径、
质心偏移等指标 → 参数扫描自动择优**。物理模型与 `codex\CGH` 的 MATLAB 实现逐位对齐（见「与 MATLAB 的一致性」）。

- 计算在本地 Python（numpy/scipy）里跑，网页只负责参数与显示；
- 设计包只是一段 `target_field(params, ctx)` 函数，写 Python 即可，不必碰编码与传播；
- 运行前自动做环境自检，失败项给出可复制的修复命令。

## 快速开始

1. 双击 **`启动后端.bat`**（需要 Node.js ≥ 18）。窗口里会打印网页地址，通常自动打开浏览器。
2. 若没自动打开，访问 <http://127.0.0.1:3100>。
3. 顶栏点 **「环境自检」** 确认全部通过（首次建议做一次）。
4. 左侧选参数 → 点 **「开始计算」**。

> 换端口：`set CGH_PORT=3101 && 启动后端.bat`。
> 换 Python：把解释器绝对路径写进项目根目录的 `.cgh-python.txt` 第一行，或 `启动后端.bat "C:\path\to\python.exe"`。
>
> **改 bat 的注意事项**：`启动后端.bat` 必须保持 **纯 ASCII + CRLF 换行**。cmd.exe 按系统 OEM 代码页
> （中文 Windows 是 GBK）逐字节解析 bat，文件里一旦出现 UTF-8 中文注释就会串行，启动前冒出
> `'xxx' 不是内部或外部命令` 之类的假报错。中文提示统一由 `backend.mjs` 打印（bat 里先 `chcp 65001`）。

Python 需要 `numpy` 与 `scipy`。缺依赖时自检会给出 `pip install numpy scipy`。

## 参数面板

参数按**角色**分层，先回答「这个值我到底该不该动」，再谈怎么改：

| 角色 | 含义 | 面板行为 |
|---|---|---|
| 设计旋钮 | 日常真正要调的：编码方式、0/+1 间距、零级补光 | 默认展开，蓝色圆点 |
| 标定项 | 实测校准值：入射腰斑、目标芯径映射 | 琥珀色圆点；自动优化默认**不勾** |
| 装置常量 | 换硬件才改：波长、SLM 像素/尺寸、各段距离、焦距 | 整组折叠，不占版面 |
| 评价定义 | 四个窗口半宽 | 单独一小节，提示「改了就不可比」 |
| 数值 / 输出 / 显示 | 补零、FFT、精度、BMP、gamma、配色 | 收在「高级参数」或末组 |

- **依赖灰显**：只在某个取值下生效的参数（如「迭代编码次数」仅 `iterative_gs` 生效）在不满足条件时直接灰掉，
  并标出「仅当『编码方式』为 iterative_gs 时生效」，避免出现「改了没反应」。
- **配置体检**：面板顶部常驻一张体检卡。它用静态规则检查自相矛盾的组合——旧版正弦编码、零级补光开着、
  腰斑填了非实测值、窗口装不下光斑、FFT 尺寸偏小等——每条都给「修复」按钮，点了立刻改草稿（不用先保存）。
  改任何参数后体检会在 250 ms 内重算。
- **预设构型**：实验基线（0.41 mm + 2 像素双相位 + 零级补光 0）、近场优先、编码对比、快速试算，一键把
  一组已知自洽的值写进草稿。
- **一行一个参数**：标签在左、控件在右、单位跟在数值后；`advanced` 参数收在每组的「高级参数」里。
- **分组可折叠**，标题右侧是参数个数；折叠状态记在本机，刷新后保持。
- **搜索框**：输入中文名或 key 即可过滤，命中项自动展开所在分组；「全展 / 全收」一键处理所有分组。
- **滑块**：`slider: true` 的参数（入射腰斑、零级补光半径）直接给滑杆 + 数字框，拖动即时改草稿。
- **说明**：每个参数右侧的 `?` 点开显示完整说明，默认不占版面。
- 改动过的参数左侧有橙色竖条，底部浮出「N 项未保存 / 保存参数 / 还原」。

## 看图和判读

- **总览图带框**：近场/远场总览上画出 `0 级`（黄）、`+1 级`（蓝）、`-1 级`（虚线灰）三个评价窗口，
  框的位置、尺寸就是参与指标统计的窗口，鼠标悬停可看中心与半宽。
- **点击放大**：点任意图像打开大图，**滚轮以光标为中心缩放、拖拽平移、双击复位、Esc 关闭**；
  总览的窗口框在大图里同步显示，方便确认「哪个点是零级、哪个是 +1」。
- **归一化**：默认「窗口内」——按 0/+1 窗口内的峰值定满量程。相机面上零级和双相位残余条纹级次
  常比一级亮几十倍，按「全图」峰值归一化会把一级压成灰雾，看起来像是编码失败。切回「全图」可看真实动态范围。
- **诊断卡**：自动回答「一级和理想一级为什么不一样」，给出近/远场相关系数、可分辨尺度 `λz/w`、
  目标最小结构、弱照明能量占比，并逐条解释。若结论是照明不够，会给出「用 1.2 mm 试算」的按钮
  （只改草稿不落盘，用来验证编码链路本身是否正常）。

## 设计包：把你的 CGH 设计搬进来

网页只认「设计包」。把原始脚本变成设计包有两条路：

**A. 交给 AI 整理（推荐）**
1. 点顶栏 **「整理脚本提示词」**，弹窗里选模板：
   **「MATLAB 脚本」**（原 `.m` 常用）或 **「通用 / 其他语言」**；
2. **复制全文**，把提示词 + 你的脚本 + 「想让相机看到什么」一起粘给 AI；
   MATLAB 版提示词已内含语法对照表、单位换算、`meshgrid` 方向与索引陷阱、必须删掉的语句清单；
3. AI 会返回 `manifest.json` 与 `design.py` 两个文件；
4. 在 `designs/` 下新建目录（如 `designs/my_pack/`），把两个文件放进去；
5. 回网页点 **「重新扫描」**，在下拉里选中新包。

**B. 手写（模板已给）**
复制 `designs/_template` 为 `designs/my_pack`，改 `manifest.json` 的参数表与 `design.py` 的
`target_field`。约定只有三条：

```python
def target_field(params, ctx):
    g = ctx.grid(nx=720, ny=720, extent_m=2.5e-3)   # x/y 单位米，第 0 行 = +y
    field = ctx.sdk.gaussian(g.x, g.y, params["waist_mm"] * 1e-3).astype(complex)
    return {"field": field, "extent_m": (2.5e-3, 2.5e-3)}
```

* 只返回**相机（近场）平面上的目标复场**，不要加载波、不要反传、不要量化；
* 场在 (0, 0) 居中，`extent_m` 是它覆盖的物理宽高；
* 参数在 `manifest.json` 里声明，网页自动生成控件与扫描项。

`ctx.sdk`（即 `engine/cgh_sdk.py`）提供 `grid / gaussian / disk / ring / vortex / tilt / lens /
normalize / lp_modes / combo / image_field` 等函数，汉字或图片掩模用 `image_field`。
完整规范见 `docs/设计包规范.md`。

## 能算的指标

每个平面（近场、远场）各分「零级窗口 / 一级窗口 / 跨窗口」三块：

- **1/e² 半径**：径向平均剖面过峰值 1/e² 处内插（`r1e2_mm`），分轴 `r1e2_x/y_mm`；
- **包络能量半径**：50% / 86.5% / 90%（`r_ee50/865/90_mm`）—— 环形、多瓣光斑更稳健；
- **D4σ**：二阶矩 `4σ`；
- **质心与偏移**：相对理论一级中心的 `offset_x/y_mm`、`offset_mm`、`offset_px`；
- **形态**：与理想光场的强度相关系数、归一化 RMSE；
- **能量**：零级/一级窗口能量占比、零级/一级峰值比、整平面相对 SLM 功率。

顶栏「应填的两个数值」两张卡片可切换成任意指标，默认是**远场 1/e² 半径**与**近场 1/e² 半径**。

## 参数扫描

「参数扫描」页勾选任意 `sweepable` 参数（入射腰斑、0/+1 间距、编码方式、补零倍数、FFT 尺寸、设计包自己的
参数……），给步长或自定义取值，选评分指标（综合 / 相关系数 / 能量占比 / 零级抑制 / 半径……），
一键跑完全部组合，结果表按评分排序，可「应用」最优组合回参数面板。

`fast` 档为半分辨率 + 单精度（约 3.4 s/组），`full` 档为全分辨率（约 10 s/组，含 BMP）。

## 自动优化

「自动优化」页不穷举取值，只给**区间**，由后端按「一级 vs 理想一级的相似系数」自己找方向：

1. 勾选可变参数：设计旋钮标「推荐」的默认已勾，**标定项默认不勾**（优化它等于让算法吸收装调误差）；
2. 数值参数填搜索区间，默认是当前值 **±30%**（标定项 ±20%），旁边有「±30%」一键重置；
   枚举参数自动穷举全部取值；
3. 选评价函数、质量档、评估上限，可勾「full 档复核」。

算法（`engine/optimize.py`）：

- **缓存去重**：所有评估走 memo，同一组参数只算一次。旧版枚举变量每轮都从旧值重扫全部选项，
  30 次预算里能重复算 6 次以上；
- **粗扫**：每个数值变量取 5 个点（当前值 ±25%/±50% 区间），枚举全试一次，就地定下最优；
- **精修**：在当前状态附近逐坐标 ±step 试探，接受即更新，整轮无改进则步长减半；
- **选优用归一化改进**：远场相似系数常年在 0.98 以上，剩余余量只有 0.02；直接平均会让近场
  0.85→0.91 的改进被远场的微小波动稀释。所以排序用「按各自剩余误差归一后的改进」（`merit`），
  展示仍然是真实的相似系数；
- **饱和提示**：基线任一平面 ≥ 0.97 时明确告诉你「已经饱和」，建议换「一级能量占比」目标；
- **full 档复核**：结束后用 full 档把基线与最优各重算一次，报告 fast 估计与 full 实测的差；
- **能量保底**：一级能量低于基线 60% 时按比例软惩罚，防止靠「把一级调暗」刷分。

结果给出「基线 → 最优」的相似系数、归一化改进、每个变量的前后取值、折线轨迹（含基线虚线）与逐次记录，
一键把最优参数回填到左侧面板（仍需点「保存参数」才写盘）。

**哪些参数适合变**（`engine/settings.py` 的 `optimizable` / `optimizeRank`，界面会显示理由）：

| 参数 | 结论 | 原因 |
|---|---|---|
| 编码方式 | 推荐 | 离散量只需试有限几次，直接决定零级强弱与一级效率；实测 2px 双相位 0.999 vs 旧版正弦 0.85 |
| 0/+1 间距（远场 x） | 推荐 | 真实可调的光学设计量：太近零级漏进一级窗口，太远超出视场 |
| 0/+1 间距（远场 y） | 可选 | 可让一级避开零级残余条纹，但斜向分离要留意视场 |
| 入射振幅下限 | 可选 | 只影响弱照明区权重，收益小、成本也小 |
| 入射 1/e² 半径 | 慎用 | 影响最大，但由扩束镜决定；改成 1.2 mm 只是让数字好看，装置没变 |
| 目标芯径映射 | 慎用 | 本质是放大率标定，优化它会把装调误差藏进标定里，相似系数虚高几个点 |
| 零级补光半径 | **排除** | 按定义是「牺牲一级换零级」，以一级相关为目标最优恒为 0 |
| 评价窗口半宽 | **排除** | 是评价函数的定义域，放宽窗口等于改评分标准 |
| 波长 / 距离 / SLM 尺寸 | **排除** | 硬件常量，改了等于换装置 |
| 补零倍数 / FFT 尺寸 / 精度 | **排除** | 纯数值精度，会产生虚假提升 |
| 设计包参数（权重、相位） | **排除** | 它们定义「理想」本身，目标跟着变量变，必然接近 1 |

> 优化只能在你给的起点附近找解。**起点自相矛盾时，先按体检卡修正起点，比在山谷里精细搜索有效得多**：
> 实测同一套装置，`type3_sine + 零级补光 0.2 mm` 起点近场相关 0.848、一级能量 11%、零级/一级峰值比 11.5；
> 换回 `2px 双相位 + 零级补光 0` 直接是 0.999 / 38% / 0.16，30 次优化也追不回来。

## 编码方式

「编码方式」共 7 种（`engine/encoding.py`）：

| 取值 | 说明 |
|---|---|
| `double_phase_2px` | 两列条带双相位（周期 4 px），多余光沿 x 推开，默认 |
| `double_phase_2px_y` | 两行条带，纵向分离 0/+1 时用 |
| `double_phase_1px` | 单像素棋盘，多余光推到对角 (±fs/2, ±fs/2)，零级最干净 |
| `double_phase_4px` | 四列条带（周期 8 px），编码带宽最小、对 SLM 分辨率最宽容 |
| `blazed_sinc` | 闪耀 sinc，一级效率高但零级明显 |
| `type3_sine` | 正弦型（旧版），历史对照 |
| `phase_only` | 纯相位、不做振幅补偿，仅作「不编码振幅」的下界对照 |
| `iterative_gs` | **迭代编码**（Gerchberg-Saxton / IFTA）：SLM 面施加纯相位约束、一级窗口施加目标振幅约束，靠迭代次数换形状精度 |

### 迭代编码（iterative_gs）

前面几种都是一次性解析映射：算出 SLM 面所需复场 → 逐像素写成相位，写完就结束。
迭代编码在这一步之后再接一段循环：

```
SLM 面（照明振幅 × 当前相位）
   --角谱前传--> 近场：把一级窗口内的振幅换成目标振幅（相位保留）
   --FFT--> 焦面：把一级窗口内的振幅换成目标振幅（相位保留）  ← 仅 far/both
   --反传--> SLM 面：取相位，振幅重置为照明
```

`迭代约束平面` 决定每轮约束哪个面：

| 取值 | 效果 |
|---|---|
| `both`（默认） | 近场/远场逐轮交替约束，两边都不放弃 |
| `near` | 只压近场一级，远场焦斑会明显变形 |
| `far` | 只压远场一级，近场形状会退化 |

`迭代编码次数` 默认 8，`advanced` 里可改。**不是越多越好**：纯相位 SLM 无法同时满足振幅约束，
迭代到 20 次以上，约束面上的相关还在涨，但真正送到器件的场开始掉能量（见下表 0.887→0.883）。
